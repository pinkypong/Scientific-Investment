RULE 34Probability Governance

확률을 3종으로 구분하고 서로 다르게 표기한다. Judgment를 Empirical처럼 보이지 않게 한다.

종류정의이 플랫폼에서
Empirical실제 historical data 계산가능 시 base rate (예: NAND 사이클) — 대부분 아직 INSUFF.
Model통계/시뮬 모델Monte Carlo P(상승)·백분위
Judgment정량 부족 → 판단 개입Bayesian LR·시나리오 확률

RULE 4Source Hierarchy (Evidence Tier)

  • A 규제공시·기업실적·공식 guidance·확정계약
  • B earnings call·고품질 산업데이터·주요 sell-side
  • C Reuters/Bloomberg/FT·산업지·전문가
  • D X·Reddit·블로그·루머
Tier C/D는 단독으로 핵심 valuation assumption을 변경할 수 없다. News는 valuation을 직접 바꾸지 않고 Assumption Review만 트리거(§Rule 3).

RULE 33Anti-Hallucination (준수 중)

  • 결측 재무 임의충전 금지 · 출처없는 확률/WACC/terminal growth 금지
  • 동일 source 중복 evidence 금지(예: LS증권 데일리 7건→1~2로 축약, 메리츠 중복→1)
  • 현재가에 맞춘 가정 조작 금지 · Bull/Base/Bear 기계적 배정 금지
  • 저confidence 결과를 확정 적정가처럼 표기 금지 · 과잉정밀 금지
근거 부족 시 숫자 대신 INSUFFICIENT EVIDENCE를 표시한다(빈칸 채우기보다 빈칸 유지).

CHECK숫자 검증 방법 (핵심)

1. Revenue Bridge — 매출을 요약 말고 재구성

Revenue = Volume × ASP (메모리: Bit Shipment × $/Bit). 성장률 = Volume + ASP + Mix + FX + Other 로 분해.
검산 예(키움 삼성 HBM): (출하 +109%)×(ASP +81%) = +278% ≈ 리포트 +269% → 정합 ✓

2. EPS 재구성 & 역기저(base effect)

Revenue → Gross → Operating → NOPAT → Net → EPS 로 걸어 재계산 후 리포트값과 대조. YoY만 보지 않고 QoQ·2yr CAGR·정규화·cycle-adjusted 병행. Forward EPS 하락 시 "역기저 vs 실제 악화" 분리.

3. 성장률 Bridge · Historical ≠ Future

"최근 +171% → 향후 +65%면 보수적" 같은 단순 외삽 금지. CXMT 공급·Big3 증설·HBM allocation·ASP·utilization을 각각 검토.

4. 독립 수급 모델 (bottom-up)

HBM Demand = AI accel units × stacks/accel × GB/stack. CXMT: Wafer capacity → Gross bit → Yield-adj bit → Marketable supply (capacity ≠ bit output). Capacity share ≠ Shipment ≠ Revenue ≠ Profit share.

5. DCF 엔진 (단계별, 각 가정 노출)

Revenue → EBIT → NOPAT(=EBIT×(1−tax)) → +D&A −CapEx −ΔNWC = FCFF → ÷(WACC) → +Terminal(FCFF×(1+g)/(WACC−g)) → EV → +순현금 → Equity → ÷주식수 → 주당가치. 조건검증: WACC > g. WACC = we×CoE + wd×kd×(1−tax), CoE = rf + β×ERP.

6. Reverse DCF — 주가 내재 기대 역산

현재가·순현금·WACC·g 고정 → EV=ΣFCFF/(1+WACC)^t+TV, 한 변수(예 FCFF CAGR)만 solve(§A8). 예(삼성): 현재가 정당화에 10년 FCFF CAGR ≈ 28% 필요 → 시장=공격적 업사이클.

7. Monte Carlo (분포·상관)

forward EPS 분포(컨센 low/mean/high) × 사이클 P/E 분포, 20,000회 → 공정가치 분포·P(FV>가). 변수 상관 반영(SanDisk regime-mixture). "정답 생성기" 아님 — 가정에 민감.

8. Bayesian (prior → posterior)

사건 정의 → base rate(prior) → 증거별 우도비(LR, 중복원본 금지) → posterior. 예(SanDisk 구조적 이익): 25% → 59.5%(LR: NBM 2.2·자본환원 1.6·프레임 1.25).

9. Sanity Checks (자동 거부/경고)

WACC ≤ g → ERROR · 음수 주식수 → ERROR · TV 비중 과대 → WARNING · 극단적 implied growth → WARNING · DCF vs 주가 급괴리 → REVIEW · 컨센서스 불가능 수치(삼성 2026 매출 +119%) → DATA CONFLICT 거부(가짜 FV 금지).

CHECK리포트 낙관성 3단계 검증 + 실증

  1. 내부 산수 검산
  2. 컨센서스 대조(불일치=과낙관 신호)
  3. 실적·역사 대조
실증 — 키움 삼성 HBM OP 83조(2027, 단독) vs 삼성 전사 OP 실측(2021 51.6·2025 43.6조) → 역대최대의 1.6배 + OPM 75% ⇒ 과낙관 高. 컨센서스 2028 EPS −33%가 반박.
연동 상태 — 정성 검증은 VALUATION→CHECK에서 작동. 확률 직접연동은 SanDisk(Bayesian)만; 나머지는 컨센서스 EPS 경유 간접. (다음: 과낙관 페널티 직접 반영 옵션)
