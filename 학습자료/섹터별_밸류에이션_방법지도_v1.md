# 섹터별 밸류에이션 방법 지도 v1 (다모다란 기반)

> 핵심 원칙: **"하나의 P/E로 통일하지 말라."** 섹터마다 현금흐름 정의·위험·성장동인이 달라 방법과 companion 멀티플이 다르다.
> 벤치마크 데이터: `damodaran_allsectors.json` (54섹터, US·2026.1). 방법론: `다모다란_밸류에이션_스터디_v1.md`.
> 시장 기준: implied ERP 4.23% · 무위험 4.18%(2025말, US).

## 사용법 (3단계)
1. 종목의 **섹터를 식별** → allsectors.json에서 그 행을 벤치마크로.
2. 아래 **섹터별 권장 방법**으로 내재가치 산출(리포트 숫자 그대로 믿지 말고 재구성).
3. **companion 멀티플**로 상대가치 교차검증 + 리포트의 목표배수가 섹터 대비 어디인지 판정.

---

## A. 금융 (은행·보험·증권·자산운용)
- **왜 다른가**: 부채가 "원재료"라 FCFF·EV/EBITDA **무의미**(EV/EBITDA가 NA인 이유). 규제자본이 재투자.
- **방법**: 배당할인(DDM) / FCFE / **초과수익모형 = (ROE − COE) × 자기자본 → 성장**. 은행은 자기자본비용으로 순이익 할인.
- **companion**: **P/B ↔ ROE** (회귀선에서 벗어난 종목이 미스프라이싱). P/B가 높으면 ROE로 정당화되는지 확인.
- **벤치마크(예)**: Bank(Money Center) ROE 12.9%·PBV 1.62·Ke 7.3% · Insurance(Prop/Cas) ROE 18.7%·PBV 2.02 · Investments&AM ROE 15.9%·PBV 2.49.
- **체크**: PBV/ROE 정합? ROE > COE면 P/B>1 정당. 부실·대손 사이클 반영.

## B. 헬스케어 — 세부업종별로 갈림
- **바이오(Drugs Biotechnology)**: 파이프라인 = **의사결정나무 / rNPV**(임상단계별 성공확률×허가시 가치 − 실패). 현재 적자(net −5%)·PE 무의미. 성공확률·TAM·특허절벽이 동인. β1.14·Ke 9.0%.
- **제약(Pharmaceutical)**: 성숙 캐시카우 + 파이프라인. **DCF(안정)+특허절벽 반영**. net 18.5%·op 29.5%·EV/EBITDA 18.6·ROE 24%·fwd PE 24.
- **헬스케어 제품/장비(Healthcare Products)**: 안정 DCF·EV/EBITDA(23.4)·ROE 11%. 규제·리콜 위험.
- **병원/서비스(Support Services)**: 저마진(net 1.25%)·자본회전 사업 → EV/EBIT·ROIC(31%) 중심.

## C. 소비재 (필수/임의)
- **왜**: 브랜드 moat = 지속 초과수익(ROIC>WACC). 성장 완만·예측가능 → **안정 DCF**가 잘 맞음.
- **companion**: **PE(성장 통제=PEG)**, EV/EBITDA. 브랜드력은 마진·ROIC로 확인.
- **벤치마크**: Beverage(Soft) op 20.5%·ROIC 29%·PE fwd 23.7·PEG 1.70 · Household Products op 18.6%·ROIC 34%·EV/EBITDA 13.7 · Food Processing op 10.6%·저성장 2.7%(PEG 6.2 = 비쌈).
- **체크**: 마진·ROIC가 브랜드 스토리를 지지? 저성장인데 고 PE면 과다.

## D. 기술·반도체 (성장 + 사이클 혼재)
- **성장SW(System&App)**: **매출→목표영업마진 수렴→재투자(매출/자본)** DCF. 현 op 33%·ROIC 29%·fwd PE 34·PEG 1.65. R&D 자본화 고려.
- **반도체(사이클+성장)**: ⭐ **정규화 + 사이클조정**. peak EBITDA에 EV/EBITDA(42.7!) 곱 금지. β1.52·WACC 10.55%·정상 net 30%(fabless 포함, 메모리는↓·변동↑). 우리 메모리 프로젝트 방식(cycle P/E) 적용.
- **반도체장비**: 오더·백로그·WFE·설치기반 서비스. β1.40·EV/EBITDA 26·ROIC 28%.

## E. 에너지·소재 (원자재 사이클)
- **왜**: 상품가격이 최대 동인 → **정규화 상품가격 + 사이클조정**. peak 이익·배수 곱 금지.
- **companion**: EV/EBITDA(Oil E&P 6.2·저배수 이유=변동성), P/B. net·ROIC가 사이클 어디인지 표시.
- **벤치마크**: Oil/Gas E&P op 25%·EBITDA 43%·ROIC 13.7% · Metals&Mining op 24%·ROIC 27% · Steel op 4%(트로프성).

## F. 유틸리티·인프라·REIT (안정·규제·자산)
- **유틸리티**: 규제수익·저베타(0.24~0.41)·저 COE → **배당할인/DCF**, 규제자본수익. Utility(General) PE 18·성장 6.9%.
- **REIT**: FFO/AFFO·NAV 기반(순이익 왜곡 큼). P/B·배당. EV/EBITDA·PE 왜곡 주의.

## G. 산업재 (기계·항공/방산)
- **DCF + EV/EBITDA·EV/EBIT**. 사이클·백로그 반영. Machinery op 16%·EV/EBITDA 17·ROIC 24% · Aerospace/Defense op 8.7%·EV/EBITDA 33(방산 프리미엄)·성장 25%.

## 공통 규율 (전 섹터)
1. **정규화**: 사이클 업종은 현재이익 아닌 사이클평균. 2. **성장=ROIC×재투자**(공짜성장 금지). 3. **터미널 g ≤ 무위험(4.2%)**. 4. **멀티플엔 companion 통제**(PE↔성장, P/B↔ROE, EV/EBITDA↔재투자·세율). 5. **Value vs Price + Reverse DCF**로 시장기대 역산. 6. **라벨**: FACT/ESTIMATE/ASSUMPTION. 7. 데이터 US·USD → 한국주는 통화·CRP 조정.

## 리포트 분석 파이프라인 연결
🔬 리포트 분석 / semiconductor 스킬이 종목을 받으면: ①섹터 식별 → ②allsectors.json 벤치마크 로드 → ③이 지도의 섹터별 방법으로 리포트 숫자 재구성·검산 → ④companion 멀티플로 과낙관 판정 → ⑤Assumption Review 후보 제시(자동 변경 금지, §Rule3).
